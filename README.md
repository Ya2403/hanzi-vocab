# Hanzi Vocab

A Chinese vocabulary trainer: React + Vite + TypeScript, installable as a PWA, with all data stored locally in IndexedDB.

## Features

- **Skills (FSRS)**: words are the only thing the app schedules. Every learned word has one [FSRS](https://github.com/open-spaced-repetition/ts-fsrs) card per skill: **meaning** (hanzi → meaning), **pinyin** (hanzi → pinyin, also listening) and **recall** (meaning → hanzi), plus accuracy and the last 5 answers. Reviews use the real time since the last review, so a late review is handled correctly. A word is as strong as its weakest skill: *weak* (learned in the last 2 days, often missed, or remembered for under 3 days), *medium*, or *strong* (remembered for 3+ weeks). A skill under 70% likely to be remembered right now is *rusty*. A skill with 5+ lapses (Settings) is a 🐛 leech. Radical-only entries (氵…) have meaning and recall only.
- **Upgrading older data**: older SM-2 schedules are converted to FSRS when a skill is first used (interval → stability, ease → difficulty, review and lapse counts as they are); nothing in storage is rewritten. Even older single-schedule words (and backups) are migrated as before.
- **Practice** (home tab): there is no due queue. One **Start practice** button runs a session of a fixed number of exercises (10 / 20 / 30, default 20). The app picks the words in the background: each learned word skill gets a priority (most likely forgotten by FSRS first, then recent misses, then low accuracy; words learned in the last 2 days get a boost). About 80% of a session are the highest-priority words, about 20% random stronger words, one card per word, never the same word twice in a row; a missed word comes back once, as an easier card. Every answer updates FSRS (first answer per skill) and accuracy. **Focus** limits a session to some tags (e.g. before a test). The end shows exercises done, accuracy and the words that need attention, with **Another round** / **Done**. A balance hint says whether to refresh first (many rusty words) or learn new words.
- **Stats**: words by strength (weak / medium / strong, new, rusty) overall and per tag, and **readable sentences** (all their words learned) overall, per tag and per dialogue.
- **Two-step cards**: meaning and pinyin are tested together on the same characters. 1) The hanzi alone (no pinyin, no audio): what does it mean? 2) The same hanzi: how is it pronounced? 3) The full answer (hanzi, toned pinyin, meaning, example) with audio. The meaning is always multiple choice; the pinyin is multiple choice or typed. When only one of the two skills is due, both are asked, but only the due one is rescheduled (the other just records accuracy). Keys: 1–4 pick, Enter continues.
- **Exercise → skill**: 中 → EN (multiple choice) tests meaning; pinyin (choice, typing or listening) tests pinyin; EN → 中 (choice, or typing the characters) tests recall; writing tests writing; sentence cloze tests meaning and recall. A card only updates the skills it tests.
- **Automatic exercises** (on by default; Practice → Exercise settings): meaning + pinyin go on a two-step card, recall and writing on their own. The meaning is always multiple choice; pinyin is multiple choice until strong, then typed (medium pinyin sometimes gets listening); recall is multiple choice while weak, then you type the characters. Missed cards come back as multiple choice. Turn it off to choose modes yourself.
- **Pinyin options**: wrong answers sound similar (same initial or final first, then the same number of syllables), taken from your words or made from real syllables. Never two options that differ only in tones, and never another reading of the same character.
- **Tones** (Settings): *ignore* (default): pinyin options without tone marks, typed pinyin checked on spelling only (ü as v or u). *Show only*: options with tone marks; typed wrong tones still count but are recorded as a tone error. *Required*: wrong tones = Close (Hard). The answer always shows tone marks.
- **Flashcards**: one grade row per tested skill. The hanzi side has Meaning and Pinyin (Forgot / Knew it, plus Wrong tone when tones aren't ignored); the English side has Recall. Pinyin is never shown before it's graded.
- **Answer statistics**: every answer in Learn and Practice updates the tested skill's accuracy (correct/total) and its last 5 results (Learn: 中 → EN counts for meaning, listening for pinyin, EN → 中 and typing for recall).
- **Word list**: add, edit and delete words (hanzi, pinyin, meaning, optional example sentence, tags). Pinyin is generated automatically with `pinyin-pro` until you type your own. Search works with or without tone marks (`ni hao` finds 你好), and you can filter by tag.
- **Sentences** (Words tab → Sentences): sentences are items of their own: Chinese, pinyin (generated until edited), an English translation, tags, notes and, for dialogue lines, the dialogue they belong to. Each sentence links automatically to the words of your list it contains (Intl.Segmenter word segments, whole words first, then single characters), shown as tappable chips that open the word. Search, tag filter, add, edit and delete like words; a sentence shows *readable* once all its words are learned. Sentences are not scheduled: they are the material words are reviewed in. Word cards show the word's linked sentences as examples, with the translation underneath.
- **Dialogues** (Words tab → Dialogues): a lesson text with a title (e.g. 第一课 课文3), tags and ordered lines, each a sentence with a speaker (A / B or a name). Play one line or the whole dialogue, edit title, tags and speakers, reorder lines, or remove a line (it stays as a loose sentence). Deleting a dialogue can keep or delete its sentences.
- **Bulk add sentences / dialogue**: like Bulk add words. Sentences: `chinese | pinyin | translation | tags` per line (empty pinyin is generated; lines without a translation are flagged). Dialogue: the same with an optional `A:` speaker, all lines becoming one dialogue in order, with a title; lines after `--- examples` are extra sentences of the lesson. The copy prompt asks an AI to read a photo of a lesson slide and return the dialogue plus its example sentences in this format. Sentences already in your list are skipped (but get the pasted translation if they had none).
- **Fill missing translations**: builds an AI prompt listing the sentences without a translation (`chinese | translation`), with a paste box and a preview.
- **From word examples to sentences**: each word's old example sentence (stored words, old backups, devices still on an older version, and the example column of Bulk add words) becomes a Sentence linked to the word, tagged like it. Its translation is kept when it had one (Tatoeba); otherwise it's marked "needs translation".
- **Learn** (tab): new words are taught here before they come up in Practice. Pick all new words or some categories. Words are taught in batches (default 6) up to a daily limit (default 15). Prerequisites come first: a character before words that use it, and components before the characters built from them (using Make Me a Hanzi data; otherwise words tagged "key" go first). After that, the order you added words is kept, and look-alikes (未/末, 吃/喝, …) are kept out of the same batch when possible. Each word gets a teaching card (hanzi, pinyin, audio, meaning, components such as 妈 = 女 woman + 马 horse, notes, example) and a quick meaning check. The batch then goes through four rounds: 中 → EN, listening, EN → 中, and an optional typing round. Misses come back later in the same round. Radical-only entries (氵, 扌, 讠) get only the two recognition rounds.
- **Typing**: EN → 中 means typing the Chinese characters with a Chinese keyboard (e.g. pinyin input on the phone); typing pinyin there just shows a reminder. Pinyin is typed in the pinyin step, with tone marks (`nǐ hǎo`), numbers (`ni3hao3`, `5` = neutral) or `v` for ü; how tones count follows the Tones setting. Meanings are never typed: they are always picked from options. An "I was right" button overrides a wrong verdict.
- **Character breakdown**: tap a word to open its detail view, or expand "Breakdown" on a flashcard back. For each character you see its components with their meanings, the radical, and the etymology, e.g. 好 = 女 + 子, "A woman 女 with a son 子". For meaning + sound characters, the parts are labelled (妈: 女 gives the meaning, 马 mǎ gives the sound). Tap a component to see other words in your list that contain it. The data, from Make Me a Hanzi, loads the first time it's needed and is cached for offline use.
- **Notes & leeches**: every word has an optional "Notes / mnemonic" field, shown in the editor, the detail view and on flashcard backs, and included in export/import. A lapse is an Again on a word that had graduated (interval ≥ 1 day). When a word reaches the leech threshold (Settings, default 5 lapses), a prompt offers to add a memory trick right away. Leeches get a 🐛 badge, a filter chip in the word list and a source option in free Practice. The editor has Reset progress and Unmark leech (after unmarking, a full threshold of new lapses is needed to flag it again).
- **Pinyin visibility**: hide pinyin on practice question sides and under example sentences (Settings switch, or the 拼音 button in a session). Tap the characters or a sentence to reveal it for that card. "Show pinyin after answering" (on by default) still shows it on the answer side. The word list has its own toggle. Writing mode keeps pinyin, since it is part of the prompt.
- **Example sentences (Tatoeba)**: about 27,800 Mandarin–English sentence pairs, converted to simplified Chinese and split into words at build time. A sentence matches a word only when the word is a whole segment (学 does not match inside 学校), with substring matching as a fallback for words the segmenter splits (图书馆). Matches are ranked by how many of the sentence's other words you have learned, then by length, and labelled "all known" or "N new words". Use **Find sentences** in the word editor, or the bulk action on Stats & data. The data (≈0.9 MB gzipped) loads the first time it is needed and is cached for offline use.
- **Focus**: Practice defaults to everything learned. The Focus button opens tag chips grouped into Lessons (tags starting with "lesson" or "HSK lesson") and Topics (other tags, plus 🐛 Leeches), with how many learned words each has.
- **Directions** (Practice with manual exercises): 中 → EN, EN → 中, 中 → 拼音, or Mixed. 中 → EN and 中 → 拼音 use the two-step card; EN → 中 tests recall. Review always follows the due skills.
- **Match pairs**: a Choice style (Practice, manual exercises) with up to 5 words at a time in two shuffled columns. Tap a word, then its match. Words matched wrongly first time are graded Again and come back later in the session.
- **Layout**: practice sessions are full screen (the app header is hidden). In landscape on tablets, a session fits the screen without scrolling: the question on the left and the answers on the right, and writing gets a drawing grid of up to 480 px. Wide screens use two columns for the word list, the setup options and Stats & data.
- **Writing** (hidden for now): writing practice (trace, then write from memory; stroke by stroke with Hanzi Writer, or free draw with scoring) is switched off in Learn, Practice and Stats; its code and any writing data are kept so it can come back.
- **Audio**: Web Speech API with a `zh-CN` voice. It can play automatically when an answer is revealed, and the speech rate is adjustable.
- **Can't listen now**: listening cards have a "Can't listen now" button. It skips the card without grading it and turns off audio exercises for the rest of the session or 15 minutes, whichever is longer; auto-play is muted too. Cards are picked without audio meanwhile, and a headphones-off icon shows in the header (and session bar). Tap it to turn listening back on.
- **Streak**: a day counts when you finish at least one practice (or learn) session.
- **Bulk add**: copy the built-in prompt and give it to ChatGPT (or any AI chat) with a PDF, photo or list, then paste the reply back. The expected format is one word per line, `hanzi | pinyin | meaning | example | tags`. The parser also accepts markdown tables, tab-separated rows, numbered pinyin (`ni3 hao3`) and JSON. A preview shows new words, duplicates and unreadable lines before anything is saved.
- **Sync between devices** (Stats → Sync): sign in with Google and your words, sentences, dialogues, progress, deletions and streak sync automatically through Firebase (Firestore), so all your devices stay the same. The app is still hosted on GitHub Pages; Firebase only stores the data, under `users/{uid}/…`, and the security rules let each signed-in user access only their own data. Each device keeps working offline and catches up when online. When the same word was changed on two devices, the newer change wins, and the same word added separately on two devices is merged into one. Settings stay per device. The Firebase code is only loaded once sync is turned on.
- **Backup**: export and import JSON, including sentences and dialogues (old backups still import; their word examples become sentences). Merge skips words whose hanzi you already have and sentences whose text you already have; Replace swaps out everything.
- **Keyboard shortcuts**: Space flips a card, 1–4 grades it or picks an option, and Enter continues.

## Development

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check + production build with service worker
npm run preview   # serve the production build (test PWA install/offline here)
npm test          # unit tests (Vitest)
```

## Structure

```
src/
  lib/          data model and pure logic
    types.ts      Word / SrsState / streak types
    db.ts         IndexedDB (idb): `words` and `meta` stores
    srs.ts        SM-2 scheduling
    streak.ts, date.ts, pinyin.ts, speech.ts, io.ts, settings.ts
  store.tsx     React context wrapping the DB (words, streak, daily count)
  components/   Flashcard, MultipleChoice, Session (queue/grading), WordForm, …
  screens/      Words, Review, Practice, Stats & data
```

Import format: `{ "words": [ { "hanzi": "猫", "meaning": "cat", "tags": ["animals"] } ] }`. Only `hanzi` and `meaning` are required. Missing pinyin is generated, and missing SRS data starts as a new card.
